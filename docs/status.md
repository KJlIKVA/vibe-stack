## Как остановить, если что-то пойдёт не так
1. **Быстро:** Notion → «Настройки» → «Пауза».
2. **Только песочницу:** `config.yaml` → `sandbox.enabled: false` (посты выходят без пометки, остальное работает).
3. **Полностью выключить расписание:** `gh variable set VIBE_STACK_ENABLED --body false`.

### 2. Песочница: исправления по ревью, потом включить (`sandbox.enabled: true`)

- **[высокий] npm.** Установка может выполнить код пакета с сетью: git-зависимость запускает вложенный `npm install`, а её `.npmrc` подменяет `git`.
  - Перейти на образ с npm 11 (`node:24-slim`) и флаги `--allow-git=none --allow-remote=none --allow-file=none --allow-directory=none`, плюс `--git=/bin/false`.
  - В идеале — сеть для установки только через прокси со списком разрешённых адресов (registry.npmjs.org, pypi.org, files.pythonhosted.org).
- **[высокий при низкой вероятности] Побег из контейнера → отравление кэша Actions.**
  - Запускать контейнеры под gVisor (`--runtime=runsc`).
  - Выключить `enable-cache` у setup-uv в job с секретами и правами на запись (`_run.yml` run/save, `sandbox.yml` save).
- **[средний] Сквоттинг пакета.** Чужой пакет может прописать в метаданных ссылку на чужой репозиторий. Решение: проверять provenance — PEP 740 у PyPI, `dist.attestations` у npm. Без provenance пометку не ставить (это ваше решение — сколько пометок мы потеряем).
- **[средний] Надёжность runner:**
  - ограничить вывод (`Popen` с лимитом байт, `--log-driver none`);
  - писать результат после каждой заявки, обернуть каждую в try/except;
  - задать общий дедлайн и проверять место на диске;
  - не отдавать в экспорт заявки старше `max_wait` и после N попыток.
- **[средне-низкий] Сеть.** Закрыть `INPUT -i docker0`, закрыть частные диапазоны в `DOCKER-USER` (сначала разрешить ESTABLISHED,RELATED).
- **[средне-низкий] Отмена job save.** Его может отменить concurrency: оповещать и при `cancelled()`; не применённые результаты подбирать при следующем запуске.
- **[низкий]**
  - `sandbox-apply` — принимать только id из заявок этого запуска; id только строка; бинарник только из запрошенных и с именем пакета.
  - Токен в job save — только шагам `state.sh`.
  - Ключ заявки — (кандидат, версия).
  - Concurrency на уровне workflow.
  - Тестовый id для scoped npm.
  - Редиректы PyPI (follow_redirects).
- После исправлений — повторное ревью и живой тест в Actions (`gh workflow run sandbox.yml -f test=pypi:ruff`).

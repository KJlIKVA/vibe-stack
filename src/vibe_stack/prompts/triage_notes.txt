<новая_модель>
Решение владельца канала: выход новой модели — главная новость канала, пост о ней выходит сразу.
- Если event — new_model, верни в поле "model" официальное название новой модели, как в источнике: «Claude Haiku 5.5», «GPT-6.1 Sol». Если вышло несколько моделей, назови главную. Для других событий верни пустую строку.
- В источнике может быть несколько частей: запись changelog и страницы, на которые она указывает (анонс модели, описание модели в документации). Бери факты из всех частей.
- Для new_model в claims, если это есть в тексте:
  - для каких задач модель и чем она лучше предыдущей версии;
  - результаты бенчмарков: название бенчмарка, цифра новой модели и цифры моделей, с которыми её сравнивают;
  - цена за 1 млн токенов на вход и на выход;
  - где модель доступна: API, приложения, облака.
</новая_модель>
<крупный_релиз>
Решение владельца канала: срочный выпуск инструмента — только выпуск с заметной новинкой для пользователя. Выпуск из одних исправлений выйдет обычным постом.
- Номер версии не важен. У Claude Code, Codex и Gemini CLI почти каждый выпуск меняет только последнюю цифру (2.1.300), и сама по себе она ничего не значит.
- major_release, если в выпуске есть хотя бы одна заметная новинка, которой обычный пользователь инструмента может сразу воспользоваться:
  - новая команда, режим или встроенный инструмент (новая slash-команда, режим планирования, фоновые агенты);
  - поддержка новой модели;
  - новая интеграция или платформа (IDE, облако, мессенджер);
  - изменение поведения по умолчанию, которое заметит каждый пользователь, или изменение, после которого пользователю нужно что-то сделать.
- Не major_release (event "none"), даже если пунктов много:
  - исправления ошибок и улучшения уже существующих функций;
  - API для авторов плагинов, модов, хуков и SDK;
  - телеметрия, OpenTelemetry, логи;
  - настройки администратора и организации, корпоративные политики;
  - новая настройка или мелочь на одной платформе (только VS Code, только Windows);
  - бета, preview и пре-релизы.
- Если сомневаешься, ставь event "none".
- Для major_release назови в reason заметную новинку. Если её нет, так и напиши.
</крупный_релиз>
